## 当前版本的证据范围

这是用于选题和导师讨论的**初稿**，不是已完成的河西走廊区域系统综述。本次学术数据库与期刊访问受网络策略限制，区域直接文献未完成检索及全文核验。10 篇背景与方法参考文献依据已有知识整理，本次未复核出版者记录或全文。不能据此宣称区域研究空白、国内首次或确定的梭梭退化阈值。

“结果”页区分跨物种文献认识和课题预期成果；没有虚构本地调查数据。27 林分、54 样方和约 540 标记株仅为工作量示例，需预调查后调整。用户撤回的论文示例及其数值未作为核心证据。

后续应补齐区域直接文献、造林档案及现场可行性信息，逐篇核实“已有研究做到什么程度”，再确定论文创新点。

## 文件生成与验证

生成脚本：[scripts/build_review.py](scripts/build_review.py)。使用 Python 3、python-pptx、openpyxl 和 Pillow；字体为 Noto Sans CJK。安装依赖后执行：

```bash
python scripts/build_review.py
```

脚本会重新生成 PPT、Excel、讲稿和内容清单。PDF 可用 LibreOffice 将 PPT 转换生成；预览图、压缩包和交付检查记录是本次导出产物，生成脚本不自动刷新它们。运行前请备份手动编辑的汇报文件。

本次验证包括 PPT 与 PDF 均为 28 页、逐页备注存在、Excel 工作表可读、PDF 页面边界检查及代表页面目视检查。此类文件验证不代表文献已完成学术核验。
